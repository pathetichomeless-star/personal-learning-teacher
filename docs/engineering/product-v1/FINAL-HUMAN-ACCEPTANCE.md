# PRODUCT V1 最终人工验收脚本（唯一一次人工验证）

> 本脚本为 **PREPARE ONLY**：本次自动化运行 **不执行** 任何人工测试。
> 由产品负责人（你）在空闲时间按本脚本执行一次完整验收。
> 全流程约 60–90 分钟；25 个场景可分批完成，但请一次性给出最终总评。

## 0. 验收对象与边界

| 项目 | 值 |
|---|---|
| 客户端 | py-xiaozhi（Mac），已指向 Product V1 测试 sidecar（OTA 已切换） |
| OTA | `http://192.0.2.1:28311/xiaozhi/ota/` → WS `ws://192.0.2.1:28310/xiaozhi/v1/` |
| 控制台 | `http://192.0.2.1:28312/`（局域网浏览器打开，中文界面） |
| 上游 | 真实 Qwen Realtime（音频到音频，语音 Tina，模型 qwen3.8-omni-flash-realtime） |
| 隔离 | 主链路 `xiaozhi-rtl-bridge`（8110/8111）、Workbench、旧栈均未被改动 |
| 只读边界 | 本控制台 **不会写入** Workbench；模型 / 音色 / VAD / 音频参数不可修改 |

> 这是 Product V1 的**唯一**人工验收。验收中的真实对话由你本人发起；自动化运行没有、也不会再打开任何额外会话。

## 1. 验收前准备（10 分钟）

1. **取控制台令牌**（只在你的终端显示，请勿写入任何仓库文件或聊天记录）：

```bash
ssh xiaozhi-nas 'docker exec xiaozhi-product-v1-sidecar cat /app/secrets/product_v1_admin_token'
```

2. **确认 sidecar 健康**（应为 `status=ok`、`qwen_connected=0`、`qwen_sessions=0`、`dispatch_errors=0`）：

```bash
ssh xiaozhi-nas 'curl -s http://127.0.0.1:28311/health'
```

3. **启动客户端**（请在你自己的终端里启动，macOS 需要辅助功能/麦克风权限）：

```bash
cd <project-root>/client && uv run main.py
```

   启动后确认：界面出现对话面板（字幕区）；控制台"实时状态"页出现 1 个会话。

4. **打开控制台**：浏览器访问 `http://192.0.2.1:28312/` → 在顶部"管理员令牌"输入框粘贴令牌 → 点击"连接" → 右上角出现已连接状态。

5. **记录验收环境**：验收日期时间、客户端版本、sidecar 镜像版本（控制台"仪表盘"页可见）。

## 2. 验收场景（25 项；每项记录 通过 / 失败 / 备注）

> 对话用自然口语即可；每项先看**行为是否合理**，再看备注中的硬性检查点。

### A. 基础对话（1–3）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 1 | 中文自然聊天 | 用中文闲聊 2–3 句（如"今天天气不错，我们聊两句"） | 中文顺畅回应，语气自然，无生硬模板感；无标签式内容（不出现"意图：""活动："之类提示词） |
| 2 | 英文自由对话 | "Let's talk in English. Tell me about your day." | 切换到英文顺畅对话；语法自然；字幕同步 |
| 3 | 酒店场景 | "我们练一下酒店英语" 然后说 "I'd like to check in." | 进入酒店场景对话，回应贴合前台/入住语境；可多轮推进 |

### B. 词汇教学准确性（4–6）—— 本次重点

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 4 | 词汇拼写（canonical） | 问"街道用英语怎么说？"，再问"street 怎么拼？" | **必须是 street**（不是 strit/scret 等近似拼写）；"怎么拼"要逐字母拼出真实单词 |
| 5 | 发音 / IPA | 问"street 怎么读？" | 读音说明与拼写**分开**；不得用发音近似拼写替代单词；不得把音标当成单词说成"strit" |
| 6 | 解释 → 自动恢复 | 在场景 3 的酒店对话中插入"accommodation 是什么意思？" | 先解释该词（拼写正确），随后**自动回到**酒店对话，不与场景脱节 |

补充抽测（可选，若发现任何拼写异常请记录原句）：船→ship、羊→sheep、酒店→hotel、行李→luggage、预订→book/reserve（按语境）。

### C. 学习控制（7–11）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 7 | 重复 | 说"再说一遍" | 重复上一句（或换一种更慢的说法），不跳出当前活动 |
| 8 | 继续 | 说"继续" | 顺着当前话题推进，不重新开始 |
| 9 | 语速 | 说"以后说慢一点，记住" | 确认记住（简短中文一句），随后语速明显放慢；控制台"记忆"页出现 speed=slow |
| 10 | 难度 | 说"以后简单一点，记住" | 确认记住；随后用词/句式变简单；控制台"记忆"页出现 difficulty=easy |
| 11 | 活动切换 | 说"我们聊点别的，随便聊聊" | 平滑切回自由聊天（活动切换生效，不卡在旧场景） |

### D. 记忆（12–14）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 12 | Memory 保存 | 完成场景 9 后，打开控制台"记忆"页 | 可见 `speed=slow`（来源 explicit_user）；刷新后仍在 |
| 13 | 新会话记忆 | 重启客户端（或断开重连）后说一句英文 | 语速偏好仍然生效（新会话加载记忆）；控制台"记忆"页数据仍在 |
| 14 | Memory 忘记 | 说"忘掉这个偏好" | 简短确认；控制台"记忆"页对应条目消失（刷新后不回来） |

### E. 知识库（15–16）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 15 | Knowledge 命中 | ① 控制台"知识库"页新建数据集"验收资料"，添加文档："酒店前台：退房时间是中午十二点。行李可以寄存在前台。" ② 对话中问"退房时间是几点？" | 回答内容来自该文档（十二点），且不编造额外条款；控制台"知识库"页可见数据集/文档 |
| 16 | Knowledge 未命中 | 问一个文档里没有的问题（如"这家酒店有游泳池吗？"） | 诚实回答"没有相关记录/不确定"，**不得编造**酒店设施 |

### F. Workbench 课程（17–18）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 17 | 继续上次的课 | 说"继续上次的课" | 能说出当前课次/主题（与"课程进度"页一致，如 U12 一般过去时），并带出 1–2 个学习目标 |

> 注意：Workbench 为只读数据源。控制台不提供任何写入入口（验收时请顺带确认）。

### G. 控制台与人机交互（19–25）

| # | 场景 | 操作 | 预期 / 通过标准 |
|---|---|---|---|
| 19 | Admin 角色变更 | "角色与教学"页：把角色名改为"小美"→ 预览（应显示变更项与将生成的版本号）→ 应用（需确认）→ 回到对话说"你叫什么名字？" | 对话中角色名变为"小美"（热生效，无需重启）；随后在页面**回滚**到原版本 → 对话恢复"小智" |

| 21 | 打断 | 助手说话途中直接插话（Ctrl+Q 或直接说话） | 助手立即停止并回应新内容；控制台"实时状态"页可见打断计数增加 |
| 22 | 无旧音频恢复 | 打断后保持安静 3–5 秒 | **旧音频不得恢复播放**；只有新回应 |

| 24 | 主观音质 | 全程留意 | 无爆音、无持续杂音、无异常静音；语速自然；无明显断续 |
| 25 | Admin 基础操作 | 依次点击 8 个页面：仪表盘 / 实时状态 / 诊断 / 角色与教学 / 记忆 / 知识库 / 课程进度 / 意图路由诊断 | 每页均能加载数据，无报错；课程进度页无任何写入按钮；令牌可"清除"并重新"连接" |
