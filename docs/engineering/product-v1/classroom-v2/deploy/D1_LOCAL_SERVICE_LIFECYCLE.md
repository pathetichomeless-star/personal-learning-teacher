## 1. 目标与非目标

### 1.1 目标
1. 用户**双击即用**，全程**不出现终端窗口**、不需要填任何 URL/Token/端口。
2. 本地服务**自动**启动、探测、恢复、清理；失败时给**可理解的中文说明**而非技术堆栈。
3. 失败**永不静默**：任何降级都在界面可见（沿用「诚实标注」原则）。
4. 与既有 V1 打包链（`client/classroom_app.spec`、`tools/build_classroom_app.sh`）**兼容演进**，不推翻。

### 1.2 非目标（本轮不做）
- 不做付费代码签名 / 公证（除非另行授权）；
- 不注册 LaunchAgent / LaunchDaemon（**不常驻**、不后台开机自启）；
- 不做多用户共享服务；
- 不连接 NAS / 生产网关。

## 2. 包结构与组件

```
小智 AI 学生课堂.app/
└── Contents/
    ├── Info.plist
    ├── MacOS/
    │   ├── 小智 AI 学生课堂        ← 主可执行（客户端 UI 进程，PyInstaller）
    │   └── classroom-gateway       ← 内嵌环回网关可执行（子进程；独立 PyInstaller target）
    ├── Frameworks/                 ← Qt / Python 运行时
    └── Resources/
        ├── app/                    ← 网关源码（app/、modules/、admin-v4 静态面）
        ├── qml/                    ← 课堂 QML
        └── icon.icns
```

**关键点**：
- 网关**内嵌于同一 bundle**（不是外部依赖、不是 `/tmp` 脚本、不是 dev venv）——满足"不依赖 dev venv / `/tmp`"的既有要求。
- 网关与客户端**同一版本号**，启动时互相校验（防半新半旧）。
- **打包产物内不得含** `secrets/`、`.env`、测试凭据（与安全方案 §3.6 共用构建期扫描）。

## 3. 启动序列（双击 → 可用）

```
① 单实例互斥检查
   └─ 已有实例？ → 聚焦既有窗口，本次进程退出（不启第二个网关）
② 环境与隔离校验（fail-closed）
   ├─ 解析数据目录（XIAOZHI_CLASSROOM_DIR > XIAOZHI_DATA_DIR > 独立默认验收目录）
   ├─ 指向【正式数据目录】→ 【拒绝启动】+ 图形化说明（不降级）
   └─ 断言不使用 NAS 地址、不读生产密钥 → 失败即退出
③ 建立【受保护 IPC 通道】（**父进程不绑定、不预占任何端口**）
   ├─ 父进程创建 `socketpair(AF_UNIX)`（或 `os.pipe()` 对），**无监听点**
   └─ 通道用途（双向）：① 父→子 下发 L-SESSION；② 子→父 上报「真实端口 + 就绪信息」
④ 启动内嵌网关子进程（`subprocess(..., pass_fds=[ipc_fd])`；**不传端口**）
   ├─ 传入：验收数据目录、日志目录、**IPC fd**（argv/env **不含**密钥、**不含**端口）
   ├─ 生成 L-SESSION 一次性会话密钥（仅内存），经 ③ 通道下发
   └─ 子进程**自己**在 `127.0.0.1` 上 `bind port 0` → OS 分配 → 经 ③ 通道上报真实端口
⑤ 就绪握手（带超时，**非阻塞**）
   ├─ 经 ③ 通道接收 `{port, ready}` 消息；并以 `GET /health`（或等价就绪端点）做**第二重**校验
   ├─ **8s 上限（H2）**：成功 → 记录 ready；**超时 → 界面提示「本地服务仍在准备…」**，
   │       并**允许后台继续初始化**（不阻塞本地阅读、不判死、不要求用户重启）
   └─ 校验：端口 + Host + 会话密钥可用（强于"端口通了"）
⑥ 加载主界面
   ├─ 默认首页 = 我的书库（LIBRARY_DEFAULT_HOME = YES）
   └─ 网络相关页按真实就绪状态呈现（未就绪 → §5.2 网络四态）
⑦ 失败降级（见 §6）
```

> **端口绑定模型（REV1B 明确 · 反模式禁令）**：端口**只**由**子进程**用 `port 0` 绑定。
> **禁止**"父进程先占一个端口 → 释放 → 再让子进程去竞争绑定"（存在 TOCTOU 抢占窗口，且无法保证子进程拿到同一端口）。
> 父进程**从始至终不绑定任何 TCP 端口**；它只通过 ③ 的**受保护 IPC**得知真实端口。

> **IPC 通道安全属性**：③ 的通道**不是监听 socket**——无 `bind`、无 `listen`、无路径名，
> 因此**同一用户的其他进程无法连接**（对应安全方案 §3.3 S1 裁定与威胁 T9）。
> **禁止**在通道建立前开任何"连上即发密钥/端口"的监听点。

**用户可见性**：①②④⑤⑦ 全部**无终端窗口**；进度以应用内**启动页**呈现（图标 + 「正在准备本地服务…」）。

## 4. 端口分配策略（REV1B：子进程绑定 + IPC 上报）

| 项 | 决定 | 理由 |
|---|---|---|
| 绑定者 | **子进程自己绑定**（父进程**不预占、不绑定**） | 消除"父占→释放→子竞争"的 TOCTOU 抢占窗口（REV1B 明确禁令） |
| 绑定地址 | **仅 `127.0.0.1`** | 安全方案 §3.4 C1；物理排除局域网/公网 |
| 端口选择 | **`bind port 0`，由 OS 分配** | 避免固定端口冲突；降低端口抢占/扫描命中（安全 §3.3 T8） |
| 端口传递 | **子进程 → 父进程**，经 §3③ 的**受保护 IPC** 通道上报 | **不写配置文件、不进前端资源、不打印日志、不进 argv/env** |
| 就绪信息 | 与端口**同一条** IPC 消息上报 `{port, ready, version}` | 单次可信上报，避免"端口先通、其实没就绪"的假就绪 |
| 端口展示 | **UI 完全不展示** | 学生不需要也不应看到技术参数 |
| 分配失败 | 子进程内重试至多 3 次 → 经 IPC 上报失败 → 降级（§6 D-6） | 有界重试，不无限循环 |

> **禁止的实现形态（务必避免）**：
> 1. 父进程 `bind(0)` 拿到端口 → `close` → 把端口号告诉子进程（**竞争窗口**）；
> 2. 父进程把端口号作为 argv/env 传给子进程；
> 3. 子进程用**固定端口**或**固定范围扫描**（可预测、易被抢占/伪造）。

## 5. 就绪判定与超时（REV1B H2：8s **非阻塞**首次就绪提示）

| 阶段 | 阈值 | 行为 |
|---|---|---|
| 子进程拉起 | 立即 | 启动失败（未拿到 pid / IPC 断开）→ 降级（§6 D-1） |
| 首轮就绪握手 | IPC 消息 + `GET /health` 双校验 | 持续等待至 **8s** |
| **8s 未就绪（H2）** | **─** | **不判死、不报错**：界面显示**非阻塞**提示「本地服务仍在准备…」，**允许后台继续初始化**；本地阅读与已发布课程**照常可用**（网络态 = 连接中） |
| 后台初始化成功 | ≤ 60s 内 | 界面**自动**由「连接中」切换为可用，**无需用户操作** |
| 后台初始化最终失败 | 60s 或 IPC 断开 | 进入 §6 D-2「重试」态（**仍然是可重试**，非永久失败） |
| 用户主动「重试」 | 单次 8s | 仍失败 → 保持「失败可重试」态 |

**就绪 ≠ 端口通**：必须通过"IPC 上报的 `ready` + 健康端点 + 会话密钥可用"**多重校验**；只 ping 端口不算就绪（防 T8 冒名进程）。

> **H2 语义澄清**：8s 是"**给用户的第一句反馈**"的时限，**不是**服务生命周期判定。
> 超时后**既不终止子进程，也不进入离线模式**——只是把界面从"加载中"改为"仍在准备…"，并继续在后台完成初始化。

## 6. 失败矩阵（每类失败都要有可理解的界面表现）

| # | 失败 | 用户可见文案（不出现技术术语） | 本地阅读 | 自动恢复 |
|---|---|---|---|---|
| D-1 | 网关子进程启动失败 | 「本地服务启动失败」+「重试」+「查看诊断」 | ✅ 可读已发布课程 | 重试按钮 |
| D-2 | 8s 未就绪 / 后台初始化最终失败 | 「本地服务仍在准备…」（8s 内非阻塞提示）；最终失败 → 「本地服务连接失败」+「重试」+「诊断」 | ✅ | 后台继续初始化；用户可「重试」 |
| D-3 | 运行中网关崩溃 | 「本地服务已重启（第 n 次）」 | ✅ | 看门狗自动重启，**上限 3 次** |
| D-4 | 重启超限 | 「本地服务多次异常，已切换为离线阅读模式」+「查看诊断」 | ✅ | 停止自动重启（防抖动风暴） |
| D-5 | 数据目录指向正式目录 | 「检测到配置指向正式数据，已停止启动以保护你的数据」 | ❌ **拒绝启动** | 无（fail-closed） |
| D-6 | 端口分配失败 | 「本地服务无法启动」+「重试」 | ✅ | 重试 ≤3 |
| D-7 | 会话建立失败 | 「本地服务连接失败」+「重试」 | ✅ | 重试 |
| D-8 | 磁盘满 / 权限不足 | 「无法写入数据目录」+「打开数据目录」 | 部分 | 用户处理后重试 |
| D-9 | 首开被系统拦截 | 「首次打开请右键 → 打开」（一次性） | — | 用户操作 |

> **原则**：**降级必须可见**。任何一项失败都不得伪装成"一切正常"（对偶于设计侧"设计样例不得替代真实状态"）。

## 7. 崩溃恢复与看门狗（REV1B H3：至多 3 次自动恢复）

```
网关子进程退出
  ├─ 退出码 0（正常关闭）→ 不重启
  └─ 非 0 → 看门狗处理
        ├─ 重启计数 < 3 且距上次重启 > 5s → 重启，界面提示「已重启（第 n 次）」
        ├─ 5s 内反复崩溃 → 判定为崩溃循环，直接进入 D-4
        └─ 重启计数 = 3 → D-4 离线阅读模式（停止自动重启）
```

- **上限（H3）**：**自动恢复至多 3 次**；达到上限后**停止自动重启**，转 D-4 离线阅读模式（防抖动风暴）。
- **退避（H3）**：重启间隔 1s → 2s → 4s（**指数退避**，上限 4s）。
- **崩溃循环门禁（H3）**：**5s 窗口内**再次崩溃即判定为崩溃循环，**直接停止自动重启**（不消耗剩余配额），转 D-4。
- **计数重置**：连续稳定运行 ≥ 5 min 后清零。
- **不吞异常**：崩溃原因写入本地诊断日志（脱敏），**不上传**。

## 8. 退出清理（防孤儿进程）

| 触发 | 行为 |
|---|---|
| 正常退出（⌘Q / 关闭窗口） | 发 `SIGTERM` 给网关 → 等待 ≤3s → 未退出则 `SIGKILL` |
| 主进程被强杀 | 网关侧**自守护**：父进程消失（`getppid()` 变化 / **IPC 通道 EOF**）→ 自杀 |
| 系统关机 | `atexit` + 信号处理；尽力清理，不阻塞关机 |
| **IPC 通道** | 关闭 `socketpair`/`pipe` 的两端；**P0/P1 无路径名产物，无需清理文件**（不存在"陈旧 sock"问题） |
| IPC 兜底（仅 P2） | 若确需 UDS 兜底：退出时删除 socket 文件；启动时若发现**陈旧** sock（无监听）→ 清理后重建 |
| 临时文件 | 仅在验收目录内清理（路径前缀校验 + 拒绝符号链接，安全 §3.5） |

**孤儿防护双保险**：① 父进程主动杀；② 子进程自守护。两者任一失效仍不会留下常驻服务。

## 9. 单实例互斥

- 锁文件：`~/Library/Application Support/<app>/run/app.lock`（`0600`）。
- 获取方式：`flock`（非阻塞）；失败 → 读锁内 PID → **探活**（进程存在）→
  - 存活 → 请求既有实例**聚焦窗口**，**本次进程退出**（不启第二个网关）；
  - 不存活（陈旧锁）→ 清理并重新获取。
- **不允许多开**：两个实例 = 两个网关 + 两套数据目录竞争，属高风险状态。

> **单实例"聚焦窗口"通道的边界（REV1B）**：该请求通道**仅承载控制指令**（"请把窗口带到前台"），
> **不得**承载/泄露 L-SESSION、端口以外的任何凭据，**不得**成为"连接即获得密钥"的入口。
> 若实现为 UDS，须限定 `0600` 且**只接受聚焦指令**（白名单指令集），其余一律拒绝。
> 该通道**独立于** §3③ 的密钥/端口 IPC 通道。

## 10. 日志与诊断（REV1B H4：入口置于「更多 → 诊断」）

| 项 | 规则 |
|---|---|
| 位置 | `~/Library/Logs/<app>/`（本机） |
| 内容 | 启动序列、端口（**内部记录可用，但不进前端**）、就绪握手结果、重启计数、错误码 |
| **禁止** | 会话密钥、管理员凭据、教材文件内容、绝对路径中的用户名（安全 §3.6 脱敏器） |
| 轮转 | 单文件 ≤ 5 MB，保留 3 份 |
| 诊断包 | 导出 zip（**先脱敏**，脱敏失败即拒绝导出）；**默认本机保存、不上传**（安全方案 S4） |
| **界面入口（H4）** | **置于「更多 → 诊断」**——**不在**主界面/顶栏/底栏设独立入口，避免学生误触；内含「导出诊断包」「打开日志文件夹」两项 |
| 可见性 | 入口二级隐藏，但**失败降级提示中的「诊断」按钮**可直接跳到该面板（保持可达性） |

## 11. 权限与系统交互边界

**不申请**：摄像头、通讯录、定位、辅助功能。
**麦克风（REV1B H5）**：仅在语音功能**确需**时**按需申请**；**用户拒绝麦克风后，文字学习继续可用**——
界面明确说明「未授权麦克风，可继续使用文字学习」，并提供「去系统设置授权」入口（可选）。
**不得**因拒绝麦克风而禁用课程阅读、文字问答、词汇/课件等非语音能力。
**不做**：`sudo`、修改系统安全设置、`spctl --master-disable`、写 `/System` 或 `/Library`、
注册开机自启、绕过 Gatekeeper。
**首开（quarantine）**：**引导用户**「右键 → 打开」（一次性）；用户拒绝则明确说明后果，**不静默绕过**。
