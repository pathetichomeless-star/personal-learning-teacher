① 设计样例 ≠ 真实状态。 画布中所有人物、音色、字幕、连接/语音状态均为视觉占位，已用 紫色虚线底 + 设计样例 显式标注。 正式 UI 中这些字段必须来自真实数据源（老师列表接口 / 语音会话事件 / 字幕事件）， 严禁以硬编码假数据替代「老师在线 / 正在讲解 / 正在聆听」等真实连接状态。

11 · REV1A/REV1B/01A 设计样例声明与实现约束

设计样例清单（禁止以样例值替代真实状态）REV1A 指令 ⑥
本画布中的以下内容均为视觉占位（设计样例），实现时必须替换为真实数据源：
· 老师姓名 / 学科 / 教学语言 / 音色 → 来自 GET /xiaozhi/v1/teacher/list（真实老师列表）
· 连接状态（老师在线 / 未连接） → 来自真实 WebSocket 会话状态
· 语音状态（正在聆听 / 正在讲解 / 待启动） → 来自真实音频会话事件
· 实时字幕内容 → 来自真实字幕事件流；无事件时显示空态，不得预填示例句子
· 数字人口型 → 无真实 TTS 音频时口型必须恒为 0，并明示「未同步」
· 教材文件名 / 页数 / 章节数 / 封面 → 来自真实知识库文档与课程元数据
· 课程与课件正文 → 来自用户教材解析产物；无用户教材时不得以内置演示课程冒充正式内容（演示样本须显式标注 local-demo）
· 待确认项数量 / 校对进度 → 来自真实校对状态，不得写死
⛔
硬性验收点：在无真实连接的情况下，正式 UI 必须显示「未连接 / 状态未知」， 不允许回退显示画布中的样例值（如「老师在线」「正在讲解」）。 QA 必须以「断开全部后端」为用例，逐一核验上述字段不出现假数据。
