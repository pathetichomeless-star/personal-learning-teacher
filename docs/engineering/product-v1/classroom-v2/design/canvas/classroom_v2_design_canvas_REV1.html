6 · 画板 K：六类界面状态

六类状态 · 正常 / 加载 / 空数据 / 离线 / 错误 / 禁用 状态不靠颜色单独传达
✅
正常
标准令牌；内容与操作完整可用
加载
骨架屏（≤300ms 不显示）；长任务用顶部渐变进度条
📚
空数据
图标 + 说明 + 单个主操作（「导入第一本教材」）
☁️
离线
顶部横幅「离线，可继续阅读本地教材」；网络操作禁用并说明原因
⚠️
错误
内联错误卡（不整页崩）+ 原因 + 「重试」；图标 + 文字，不只靠色
下一页
禁用
opacity .4 + 必须提示原因（如「未开始学习」）
