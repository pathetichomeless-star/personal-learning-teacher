# 小智 AI 学生课堂 —— 一页操作指南（普通用户 · Mac）

> 版本：RELEASE FIX 01　｜　适用：本机 Finder 双击体验　｜　无需终端、无需安装

## 一、打开应用（1 步）

1. 在 **访达（Finder）** 中进入：`<project-root>/client/dist/`
2. **双击「小智 AI 学生课堂.app」**。
   - 若首次打开提示"来自身份不明的开发者"：**右键 → 打开 → 再点"打开"**（本应用为本机构建、未做签名，属正常现象；只需一次）。
   - 不需要终端窗口，不需要安装任何东西，不需要联网。

## 二、三步开始上课

1. 点底部「**选择课程**」→ 左侧选课程、右侧选课时 → 点「**进入课堂**」。
2. 点「**开始学习**」——此后老师才开始讲解，状态由「待开始」变为「讲解/练习」。
3. 中间看课件：用课件区或底部的「上一页 / 下一页 / 重复讲解」翻页；
   翻到「随堂练习」页，点选一个答案即可看到对错与解析。

## 三、界面速览

| 区域 | 内容 |
|---|---|
| 顶部 | 当前课程 / 课时 / 状态；「全屏」；窗口较窄时「更多」里含高级设置与退出课堂 |
| 左侧 | AI 老师：名称、教学语言、音色、状态、「更换老师」（窄窗口在左条上） |
| 中间 | 课件：封面 / 单词卡 / 例句 / 练习 / 小结（英文大字 + 中文对照） |
| 右侧 | 字幕 / 词汇 / 课堂笔记（宽窗口常驻；窄窗口点底部「展开字幕」打开） |
| 底部 | 选择课程 / 开始学习 / **输入框**（输入英文句子回车提交）/ 提交；窄窗口的次级操作收进「更多」 |

## 四、必须知道的三件事

1. **这是本地演示课堂**：课程内容随应用分发、老师讲解是本地脚本、练习判定是本地规则；
   它**不代表**已接入正式教材或真实大模型。
2. 「语音对话（不可用）」是**刻意的诚实标注**——本版本未接入真实语音；文字学习与课件不受影响。
3. 老师形象是**静态占位**（数字人未启用），不影响上课；学生界面**不会**出现令牌、地址或密钥。

## 五、关于老师列表（默认不联网）

- 默认情况下课堂**不联网**：点「更换老师」会看到中文提示"老师列表未启用（演示模式默认不联网）"。这是正常状态。
- 只有维护者在本机启动演示网关、并在隔离配置中**显式开启**后，才会读取本机 Mock 老师列表。
- **保存老师不会自动连接**语音，也不会修改正式客户端配置。

## 六、退出与重新开始

- 退出：点「退出课堂」（窄窗口在顶部「更多」里）或直接关闭窗口。
- 重新开始：点「结束学习」回到未选课状态 → 重新「选择课程 → 进入课堂 → 开始学习」。

## 七、常见问题

| 现象 | 说明 |
|---|---|
| 换老师时显示"未启用" | 正常默认——演示课堂默认不联网 |
| 窗口拉得很小（≥620×620） | 底部次级按钮收进「更多」，课件区与翻页始终可用 |
| 输入框在哪 | 底部中间的输入框；输入一句英文按回车，右侧「字幕」出现「（本地模拟回应）」 |
| 出错怎么办 | 启动失败会有**图形化中文提示**；错误日志在 `~/Library/Application Support/xiaozhi-classroom-demo/logs/startup_error.log` |
